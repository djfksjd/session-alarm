# Changelog

All notable changes to Session Alarm are documented here.

## 1.0.0 — 2026-07-30

- Initial public release.
- Codex and Claude Code lifecycle hook adapters.
- First-run configuration skill and interactive CLI.
- Forty original 44.1 kHz procedural animal sounds.
- Per-event sound mapping, volume, desktop notifications, and quiet hours.
- Local-only operation with no telemetry, network requests, or third-party audio assets.
