# Contributing

Contributions are welcome.

1. Create a feature branch.
2. Keep the runtime dependency-free and compatible with Python 3.9 or newer.
3. Add or update `unittest` coverage.
4. Run `python3 -m unittest discover -s tests -v`.
5. Run both plugin validators described in `README.md`.
6. Open a pull request against `main`.

## Sound contributions

New sounds must be original procedural recipes. Do not submit recordings, extracted samples,
model-generated audio of unclear provenance, video or broadcast clips, celebrity voices, stock
effects, or imitations of identifiable copyrighted sounds. Add localized metadata and catalog tests
with the recipe.

## Pull requests

`main` is protected. Changes must arrive through a pull request and pass the required CI check.
